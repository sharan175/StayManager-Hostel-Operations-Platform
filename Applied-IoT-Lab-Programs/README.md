# Applied IoT Lab Programs (22CSU701)

| File | Program |
|---|---|
| Program1_LED_Blink_and_Switches.ino | 1(a) LED blink, 1(b) Case 1 button cycles red/green LEDs, 1(b) Case 2 two switches toggle LEDs |
| Program2_Analog_PWM_Serial.ino | 2(a) analogRead on A0, 2(b) PWM LED fade, 2(c) serial echo |
| Program3_Static_IP.ino | ESP8266 Wi-Fi with a static IP |
| Program4_Dynamic_IP.ino | ESP8266 Wi-Fi with a dynamic (DHCP) IP |
| Program5_Local_IP_Subnet_Gateway.ino | ESP8266 prints local IP, subnet mask and gateway IP |

Note: Programs 1 and 2 contain several sub-part sketches. Copy each part into its own sketch before uploading to a board. Replace `YOUR_WIFI_NAME` / `YOUR_WIFI_PASSWORD` in programs 3 to 5.
